# پیمان‌یار (PeymanPro)
### دستیار تخصصی قراردادهای پیمانکاری، بخشنامه ۵۰۹۰ و فهارس بهای سازمان برنامه و بودجه

اپلیکیشن جامع و مهندسی اندروید جهت محاسبه تاخیرات مجاز و غیرمجاز، تمدید مدت پیمان، آنالیز ضرایب قرارداد، برآورد فهارس بها و تعدیل آحاد بها مطابق ضوابط نظام فنی و اجرایی کشور (نشریه ۴۳۱۱ و بخشنامه ۵۰۹۰).

---

## 🌟 ویژگی‌های کلیدی (Key Features)

### ۱. محاسبه‌گر پیشرفته بخشنامه ۵۰۹۰
- **بند ۱ (اقساط پیش‌پرداخت):** محاسبه روزهای تمدید ناشی از تاخیر در پرداخت پیش‌پرداخت‌ها با فرمول رسمی:
  $$T = \frac{A \times (t_2 - t_1)}{P}$$
- **بند ۲ (صورت‌وضعیت‌های موقت):** محاسبه روزهای تمدید ناشی از تاخیر در پرداخت صورت‌وضعیت‌های کارکرد با فرمول رسمی:
  $$T = \frac{A \times (t_2 - t_1)}{B}$$
- **کنترل مواعد ماده ۳۷ شرایط عمومی پیمان:** اعمال مهلت ۱۰ روز رسیدگی مهندس مشاور و ۱۰ روز پرداخت کارفرما.
- **کسر همپوشانی (Overlap Deduction):** جلوگیری از همپوشانی بازه‌های زمانی موازی جهت رعایت آیین‌نامه‌ها و رویه کارشناسی شورای عالی فنی.
- **تولید خودکار لایحه تاخیرات:** امکان کپی فوری گزارش جامع مستند جهت پیوست به نامه‌ها و مکاتبات رسمی با دستگاه نظارت و کارفرما.
- **ذخیره در پایگاه‌داده محلی (Room/SQLite):** ثبت، مدیریت، ویرایش و بازیابی پرونده‌های مختلف پروژه‌ها به صورت آفلاین.

### ۲. مرورگر و برآوردگر فهارس بهای پایه
- دسته‌بندی موضوعی بر اساس رشته‌های رسمی:
  - ابنیه و ساختمان
  - تاسیسات مکانیکی
  - تاسیسات برقی
  - راه، راه‌آهن و باند فرودگاه
  - توزیع و انتقال آب
- موتور جستجوی سریع ردیف، فصل و شرح اقلام.
- ماشین‌حساب سریع برآورد برای محاسبه هزینه کارکرد بر حسب مقادیر کار به ریال و تومان.

### ۳. محاسبه‌گر ضرایب پیمان (Contract Multipliers)
- **ضریب بالاسری (Overhead):** ۱.۴۱ برای طرح‌های عمرانی و ۱.۳۰ برای طرح‌های غیرعمرانی با شرح آنالیز هزینه‌ها.
- **ضریب منطقه (Regional Factor):** پایگاه ضرایب مناطق و استان‌های کشور (تهران، خوزستان، بوشهر، سیستان، کردستان و...).
- **ضرایب پیشنهادی پیمانکار (پلوس/مینوس):** محاسبه درصد تخفیف یا افزایش پیشنهادی.
- **ضریب طبقات، ارتفاع و تجهیز کارگاه:** محاسبه ضریب کل پیمان و رقم نهایی قرارداد بر اساس برآورد پایه.

### ۴. محاسبه‌گر تعدیل آحاد بها
- فرمول رسمی سازمان برنامه: $E = B \times [ (I / I_0) - 1 ] \times F$
- تبیین ارتباط حیاتی بخشنامه ۵۰۹۰ با تعدیل و تفاوت تاخیر مجاز با تاخیر غیرمجاز.

### ۵. بانک قوانین و شرایط عمومی پیمان (نشریه ۴۳۱۱)
- متن و تحلیل مواد کلیدی پیمان: ماده ۲۸ (تحویل زمین)، ماده ۳۷ (پرداخت‌ها)، ماده ۴۹ (تعلیق)، ماده ۵۰ (خسارت تاخیرات) و ماده ۵۳ (حل اختلاف).
- چک‌لیست ۵ مرحله‌ای جمع‌آوری مدارک و مستندسازی لایحه تاخیرات.

## 🛠 معماری و تکنولوژی‌ها (Tech Stack)

- **Language:** Kotlin (100%)
- **UI Framework:** Jetpack Compose (Material 3, Dynamic Theme, Full RTL Support)
- **Architecture:** MVVM (Model-View-ViewModel) + Clean Architecture pattern
- **Database:** Android Room ORM with SQLite
- **Concurrency:** Kotlin Coroutines & StateFlow
- **Build System:** Gradle (Kotlin DSL - `build.gradle.kts`) with Version Catalog (`libs.versions.toml`)

## 🚀 نحوه اجرا و بیلد پروژه (Build & Run)

این پروژه را می‌توانید مستقیماً در **Android Studio** باز کنید:

```bash
# کلون کردن مخزن
git clone https://github.com/USERNAME/PeymanPro.git

# ورود به دایرکتوری پروژه
cd PeymanPro

# اجرای تست‌های واحد
gradle testDebugUnitTest

# بیلد نسخه دیباگ
gradle assembleDebug
```
